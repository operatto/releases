# Operatto releases

Compiled Operatto nodes, one bundle per platform for every version Operatto Cloud ships (ADR-125),
and each release's manifest `operatto-<version>.json`. No source code is published here.

- Phones: the Operatto Android app installs the linux-arm64 bundle of the version its organization's cloud runs.
- Computers: `install.sh` from a release installs and updates a node (ADR-48).
